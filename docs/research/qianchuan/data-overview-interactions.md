# 首页「数据概览」交互实录（来自真实站点）

## 指标卡（5 个，可点击切换 + 悬浮说明）
点击切换后，下方「子Tab / 按钮 / 6宫格小卡 / 图表」整体联动。悬浮每张卡显示说明气泡：

| 指标 | 悬浮说明 |
|---|---|
| 账户整体消耗(元) | 数据范围：包含本账户下，巨量千川计划和小店随心推订单投放数据，巨量千川计划包含标准投放、全域投放、品牌投放以及自然智能券。特殊说明：1. 品牌投放消耗数据每日20点更新，因此所选时间周期包含"今日"时，「消耗」「ROI类数据」统计值不含品牌投放当日数据；2. 当天数据会有波动，次日稳定。 |
| 乘方计划消耗(元) | 乘方投放期间产生的消耗。注：若计划发生了转投（如全域转投乘方），则转投前、后计划产生的消耗都纳入乘方消耗统计范围。如需查看详细数据，可前往数据-乘方数据查看。 |
| 标准投放消耗(元) | 标准投放（含小店随心推）投放期间产生的消耗。如需查看详细数据，可前往数据-竞价数据-标准投放数据查看。 |
| 全域投放消耗(元) | 全域投放期间产生的消耗。如需查看详细全域数据，可前往数据-竞价数据-全域数据查看。 |
| 品牌投放消耗(元) | 品牌投放期间产生的消耗。如需查看详细数据，可前往数据-品牌数据查看。 |

## 子 Tab（可点击）
- 账户整体 / 标准 / 全域：全部、推商品、推直播间、小店随心推
- 乘方：全部、推商品、推直播间（右侧额外多一个「乘方期间数据 ▾」下拉）
- 品牌：品牌合约、品牌竞价

## 6 宫格小指标卡（3×2，可点击 → 设为图表左轴指标）
整体消耗(元)、净成交ROI、净成交金额(元)、净成交订单数、净成交金额结算率、1小时内退款率

## 双轴折线图 + 图例下拉（可点击切换指标）
- 左轴默认「整体消耗」，右轴默认「净成交ROI」
- 图例「整体消耗 ▾」「净成交ROI ▾」各是一个下拉，选项：整体消耗、净成交金额、净成交订单数、净成交金额结算率、1小时内退款率、不选（当前另一轴占用的项置灰）
- X 轴随时间区间变化

## 其他
- 按钮：新建计划（品牌为「新建预定单」）、查看计划详情、自定义数据（均为跳转/弹窗，克隆中不跳转）
- 时间区间：今天/昨天/近7日/近30日 + 日期范围选择器
- 数据为空态（0.00 / --），与真实账户一致
