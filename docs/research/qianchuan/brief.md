## 隐私
个人中心与导航含真实账户数据，克隆一律替换为占位：
- 账号名 `ECP_1694786131382_6287` → `ECP_0000000000000_0000`
- 账号 ID `1777112062466060` → `10000000000000`
- 主体名称 `廖金华` → `示例主体`
- 绑定店铺 `云途家具 ID:18922044` → `示例店铺 ID:00000000`
- 邮箱/手机 → `a***b@example.com` / `188****0000`
